# machine_learn_0422

Este repositório é focado na aplicação prática de **Regressão Linear Simples**, explorando a correlação entre variáveis e a construção de modelos preditivos baseados no ajuste da reta ideal ($y = ax + b$).

## 📂 Conteúdo

* **dataset_exercicio_1.csv**: Dados sobre a relação entre Investimento em Marketing e Faturamento.
* **dataset_exercicio_2.csv**: Dados sobre a relação entre Anos de Experiência e Salário.
* **dataset_exercicio_3.csv**: Dados sobre a relação entre Número de Treinamentos e Produtividade.
* **exercicios_regressao_linear.ipynb**: Notebook que implementa a lógica de regressão. O projeto abrange:
    - **Análise de Dados**: Carregamento e exploração de datasets via Pandas.
    - **Cálculo de Coeficientes**: Determinação do Coeficiente de Impacto ($a$) e do Desempenho Base ($b$).
    - **Modelagem Matemática**: Construção da equação da reta para prever resultados futuros.
    - **Visualização**: Geração de gráficos de dispersão (Scatter Plot) e plotagem da linha de tendência utilizando Matplotlib.

## 🛠️ Tecnologias e Bibliotecas

As ferramentas centrais utilizadas neste projeto são:

* **Python 3**: Linguagem base.
* **Pandas**: Manipulação e tratamento de dados estruturados.
* **Matplotlib**: Criação de visualizações e gráficos estatísticos.
* **NumPy**: Suporte para cálculos matemáticos e operações em arrays.
* **Jupyter Notebook**: Ambiente para execução e apresentação dos resultados.

## 🚀 Como começar

1.  Clone este repositório:
    ```bash
    git clone https://github.com/felipe-r-regiani/exercicios_regressao_linear.git
    ```
2.  Instale as bibliotecas necessárias:
    ```bash
    pip install pandas matplotlib numpy
    ```
3.  Execute o notebook:
    - Abra o `exercicios_regressao_linear.ipynb`.
    - Execute as células para visualizar a análise de cada dataset e observar como a reta de regressão se ajusta aos dados reais de cada exercício.
